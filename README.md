# Murphy's Law Irish Pub & Grill

Static bilingual website for Murphy's Law Irish Pub & Grill in Lagoa, São Miguel, Azores.

## Cloudflare Pages settings

- Production branch: `main`
- Framework preset: None
- Build command: leave blank
- Build output directory: `/`

The repository can remain private while the deployed website is public.

## Local preview

Open `index.html` in a browser, or run a basic local web server from this directory.

## Updating the site

- Page content: `index.html`
- English and Portuguese text: `script.js`
- Styling and responsive layout: `styles.css`
- Images: `assets/`

After committing changes to `main`, Cloudflare Pages will deploy them automatically once the repository is connected.
